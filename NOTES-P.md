# NOTES-P (FV-P: PrettyDec, branch fv/wp, worktree /srv/fv-uint256-wP)

## Layout (amd64, all compiled; verify in build/vamd64.sh -> build/out/vamd64.log)
- Library programs (generated by tools/gen_libprog.py from build/ex-amd64-PrettyDec twice): `Fv256/StrProg.lean` (ChainProg + AppendUint, formatBase10,
  formatBits; no data), `Fv256/PrettyProg.lean` (StrProg + PrettyDec segment + the 5 data segments + 3 contracts; = the extraction).
- `Fv256/Amd64/P/*.lean`: the Dec fb10/AppendUint stack (DecT, DecA..DecM, StrconvMemmove, StrconvAppend) re-targeted at `StrProg` by sed
  (the PrettyDec extraction has no Dec/FormatUint segments, so the DecProg summaries cannot be moved by CodeIn). Namespace Fv256.Amd64.P. TabsOK.of_loaded is NOT
  there (data differs): it lives in `Amd64/Pd/Tabs.lean` for PrettyProg.data.
- `Fv256/PdCells.lean` (ISA independent): `pout`, `OutIs M top sep z c` (the 133-byte `out` array as cells), `cOf D` (cells after D digits: lazy separator),
  `nd`, `OutIs.zero/pad/write`, `strBytes_pretty`.  Spec pieces: PrettyMath.prettyBytes (+ prettyBytes_getD), `plen`.
- `Fv256/Amd64/Pd/`: Init (pd_init), Iter1 (udivrem + AppendUint + reload, to inner loop head), Inner (pd_inner_step/exit/loop), Pad (pd_pad_step/exit/loop),
  Tail (zero/non-zero quotient branch), Chunk (pd_chunk_core/next/final), Loop (pd_loop, induction over 19-digit chunks), Summary (pd_summary over
  PrettyProg.program: zero case, init, loop, slicebytetostring call), Lift (pd_summary_E for any extraction containing PrettyProg).
- `Fv256/Amd64/PrettyDec.lean`: statement (`correctness`) + `Witness` (copying 5-byte toy slicebytetostring, z = 1000 -> "1,000", sep ',').

## Frame facts (amd64; r = entry rsp, b = r - 384 body rsp)
out cells: cell p at address b+215-p (b+83..b+216); buf (AppendUint dst, cap 19) b+64..b+83; rem b+216, quot b+248; slots pos b+280, comma b+288,
cap b+296, y b+304, divisor b+336, bufptr b+368; saved bp b+376 (= r-8); separator spill b+400 (= r+16).  Loop frame = [(b-0x180, b+376)].
Invariant at the loop head after t chunks: D0 = 19 t digits done, cells c = cOf D0, rcx = 132 - c, rsi = c % 4, y = z / 10^D0.
The SAME offsets relative to r hold on arm64 (y r-80, divisor r-48, buf r-320, out top r-169); only the body sp differs (r-400) and saved FP/LR.
